# Chat support pixel prototype

React + Vite прототип экрана мобильного чата поддержки (по референсному скриншоту), разложенный на переиспользуемые компоненты.

## Локальный запуск

1. Установить зависимости:
   `npm install`
2. Запустить dev-сервер:
   `npm run dev`

## Сборка

`npm run build`

## Структура

- `src/components/ChatScreen.tsx`
- `src/components/MessageList.tsx`
- `src/components/QuickReplies.tsx`
- `src/components/Composer.tsx`
- `src/components/RatingCard.tsx`
- `src/data/chatPrototype.ts`
- `src/types/chat.ts`

## Примечание

Для визуальной близости использовано демо-изображение самокатов из открытого источника. Если нужен строго ваш кадр 1:1, замените `public/scooter.png`.
